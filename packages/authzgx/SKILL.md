# authzgx — prove a permission model has no escalation path

Part of the `gxkit` family; the review contract is shared with every `*gx` tool.

## Install

```sh
uvx --from "git+https://github.com/nekomario28/gxkit#subdirectory=packages/authzgx" authzgx --help
uv tool install ./packages/authzgx
```

## Write a model

```python
import authzgx as a

model = a.AuthModel(
    principals=["anonymous", "user", "admin"],
    roles=["viewer", "editor", "owner"],
    permissions=["read", "write", "delete"],
    grants=[("viewer", "read"), ("editor", "write"), ("owner", "delete")],
    inherits=[("editor", "viewer"), ("owner", "editor")],
    assigned=[("user", "editor"), ("admin", "owner")],
    sensitive=["delete"],
    low=["anonymous", "user"],
)
```

Or module-level `PRINCIPALS` / `ROLES` / `PERMISSIONS` / `GRANTS` / `INHERITS` /
`ASSIGNED` / `SENSITIVE` / `LOW`.

A principal reaches a permission when a role it holds grants it or inherits
transitively from one that does.

## The loop

1. Write the model as a Python file.
2. `authzgx inspect auth.py` — what each principal reaches, the escalation path,
   problems with stable `code`s, and `<name>.storyboard.png`. **Exit 1 on any
   error.**
3. Fix and inspect again; the storyboard boxes the role/permission at fault.
4. `authzgx render auth.py -o auth.png`.

## Severities

`error` = a real problem (`escalation`, `cyclic-inheritance`, dangling
references). `info` = dead config.

## What it catches

| code | severity | meaning |
| --- | --- | --- |
| `escalation` | error | a low principal reaches a sensitive permission (path given) |
| `cyclic-inheritance` | error | role inheritance has a cycle |
| `dangling-grant` / `dangling-assignment` / `dangling-inherit` | error | a reference names something undeclared |
| `unreachable-role` | info | no principal can reach the role |
| `orphan-permission` | info | no role grants the permission |
| `unreachable-permission` | info | no principal can reach the permission |
| `empty-role` | info | the role grants nothing |
| `no-sensitive` / `no-low` | info | escalation cannot be judged |

`escalation` is reachability: `gxcore.graph` walks
`principal → role → parent role → permission` and `shortest_path` returns the
path. Every check has a test that proves it fires on a model with the fault and
stays quiet on one without (`tests/`).
