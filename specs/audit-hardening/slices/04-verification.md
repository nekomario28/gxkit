# Consumer and CI acceptance

Run strict local checks including 100% statement coverage, strict mypy, lint,
workflow/security checks and all distribution builds. Obtain independent Codex
review of the complete substantive diff and resolve its grounded findings.

Install the candidate from its immutable Git revision with a fresh uv tool/cache
location. Replay exit-zero input, directory continuation, baseline worsening,
invalid declarations, zero intervals, tuple defaults and clean examples through
the installed gxkit command, including JSON and a storyboard smoke test.

Publish only the scoped branch/PR; bind its head and require the configured CI
jobs to succeed on that exact revision. No release/tag/PyPI publication is needed.
Close the handoff only when all checklist items and decisions match shipped
code, evidence and CI. Archive the finished spec as durable rationale.
