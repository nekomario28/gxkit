# Reaudit decisions

- **Relationship identity belongs to the domain check.** The network finding
  names its edge and endpoint; the baseline keeps comparing opaque identity
  tuples and multiplicities. Prose and counts are not identities.
- **Resolve once, display as typed.** Input identities are absolute and fixed
  before execution; the report still shows the name the person typed. The
  module cache stays keyed by resolved path, now reachable from one spelling.
- **One strictness rule for a recognized shape.** Auxiliary name collections go
  through the same member conversion as the primary ones. An unrelated shape may
  still fall back; a malformed recognized one may not.
- **A gate must be shown failing.** The coverage guard observes the executed
  environment and replays a failing command, because argv evidence alone cannot
  distinguish enforcement from a command whose failure is discarded.
- **Scope stays at the five findings.** Other un-strict conversions are recorded
  as residual observations rather than rewritten in this branch.
